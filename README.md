# To-Do List Life Dashboard

A cute & playful homepage-style dashboard to help organize your day with four integrated features:

## ✨ Features

1. **Time & Greeting Display**
   - Shows current time in HH:MM format
   - Displays current date in readable format
   - Shows time-appropriate greeting (Good morning/afternoon/evening)

2. **25-Minute Focus Timer**
   - Start, stop, and reset controls
   - Visual countdown display
   - Audio notification when timer completes

3. **Interactive To-Do List**
   - Add new tasks
   - Mark tasks as completed
   - Delete tasks
   - Input validation and user feedback
   - All tasks saved automatically

4. **Quick Website Links**
   - Add your favorite websites
   - Opens links in new tabs
   - Links saved automatically

## 🚀 How to Use

1. Simply open `index.html` in your web browser
2. The dashboard will load with all features
3. Your data is automatically saved in your browser's Local Storage
4. Refresh or close the page - your data will be there when you return!

## 🛠️ Technical Details

- Built with vanilla HTML, CSS, and JavaScript
- No frameworks or external dependencies required
- Uses browser Local Storage API for data persistence
- Responsive design works on all screen sizes
- Cute & playful aesthetic with smooth animations
